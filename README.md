# 🚀 Nexus — Modern SaaS Landing Page

A premium, fully responsive static landing page built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies — just clean, modern code.

![Nexus Preview](https://img.shields.io/badge/Status-Live-brightgreen) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## ✨ Features

- **Modern Dark Theme** — Premium glassmorphism UI with gradient accents
- **Fully Responsive** — Pixel-perfect on desktop, tablet, and mobile
- **Smooth Animations** — Intersection Observer-powered scroll animations
- **Interactive Elements** — Pricing toggle, animated counters, cursor glow effect
- **CSS Design System** — Custom properties for consistent theming
- **Accessible** — Semantic HTML, ARIA labels, keyboard navigation
- **Performance Optimized** — No external dependencies, minimal footprint
- **SEO Ready** — Proper meta tags and semantic structure

## 🏗️ Sections

1. **Hero** — Animated gradient background with floating orbs and dashboard mockup
2. **Logo Cloud** — Trusted-by brand showcase
3. **Features** — 6-card grid with hover effects
4. **How It Works** — 3-step process flow
5. **Testimonials** — Customer reviews with star ratings
6. **Pricing** — Monthly/yearly toggle with 3 tiers
7. **CTA** — Gradient call-to-action banner
8. **Footer** — Multi-column links with social icons

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/5amuel02/nexus-landing-page.git

# Open in browser
cd nexus-landing-page
open index.html
```

No build step required. Just open `index.html` in your browser.

## 🎨 Design Highlights

- **Typography**: Inter font family with 9 weight variations
- **Color Palette**: Deep dark (#0a0a0f) with purple-blue gradient accents
- **Animations**: CSS keyframes + JS Intersection Observer
- **Layout**: CSS Grid + Flexbox for responsive layouts
- **Effects**: Cursor glow tracking, floating orbs, glassmorphism navbar
